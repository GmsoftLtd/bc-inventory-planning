Planning Worksheet

Current versus proposed values, side by side, for any filtered set of items — with selective apply. The safest way to roll the app out.

Open it from Item List → Inventory Planning → Planning Worksheet, from the setup page, or by searching for Inventory Planning Worksheet.

How to use it

  1. Load Items — choose a filter on item number, item category or vendor. Every matching inventory item is calculated as a preview. Nothing is written.
  2. Read the variance message. It reports how many lines change the reorder point by more than 25%, so a large worksheet can be triaged instead of read line by line.
  3. Review the columns, starting with those large movers.
  4. Tick the lines you accept. Select All and Clear Selection help with big sets.
  5. Apply Selected — confirms the count, then applies.
Applying is not a copy of the preview.

The calculators re-run through their validated, logged path, so an apply is exactly equivalent to running each item individually. Applied lines refresh their “current” columns in place and are deselected, so you can see the effect without reloading.

What to look at first

  • Lines the variance message flagged. A reorder point that moves more than 25% is either a real correction or a data problem. Both are worth ten seconds.
  • Result codes that are not OK. An Insufficient Demand Data or Zero Demand line produced no value, so ticking it achieves nothing.
  • Notes containing warnings. Trend warnings mean the history is not describing the present. SKU notices mean planning reads a different value than the item card.
  • Policy changes. A recommended policy that differs from the current one changes how the planning engine behaves, not just by how much — review these before anything else.
Nothing on this page writes to items until you choose Apply Selected.

Loading, sorting, filtering and selecting are all safe. You can close the worksheet at any point and nothing will have changed.

A sensible rollout

Work through one item category or one vendor's range at a time rather than the whole catalogue. Each pass gives you a feel for whether the setup values — particularly the history window, the service level and the ordering cost — suit that part of your range, and you can adjust before the next pass.
