Getting started

From install to your first calculated item in about ten minutes.

1. Install

Install from AppSource. On installation the app creates its setup record with working defaults, registers itself under Manual Setup, and registers its calculation log with the standard Retention Policy module.

Nothing is calculated and no item is touched until you ask for it.

2. Assign permissions

Permission setGive it toGrants
GSO - User
Inventory Planning - User		 Planners, buyers Run the calculators, use the worksheet, read the log and setup
GSO
Inventory Planning		 Administrators The above, plus editing setup and maintaining the log

Anyone who runs standard planning while the optional dynamic provider is enabled needs at least GSO - User.

3. Review the setup

Search for Inventory Planning Setup. The defaults suit a distributor with a year of clean history:

SettingDefaultChange it if…
Demand History Window (Days)365Your range turns over much faster, or you have less than a year of data
Min Demand Observations20Your items sell on fewer than 20 distinct days a year
Default Service Level %95Your business targets a different availability level
Ordering Cost (S)50You know your real cost of raising and receiving one order
Holding Rate0.25Your cost of capital and storage differs from 25% a year
If you manufacture or assemble, turn on “Count Consumption as Demand”.

Without it, a component consumed by production shows no demand at all, because it is never sold. Every purchased component will report Zero Demand and no values will be produced.

The full field-by-field reference is in Setup reference.

4. Calculate one item you know well

Open an item whose demand you could describe from memory — that is what makes the first result meaningful.

Item Card → Inventory Planning → Calculate All Planning Values.

The app runs everything in dependency order: policy advice, then safety stock, then reorder point (fed the fresh safety stock, not the stored one), then EOQ, then maximum inventory. It reports what it found and why.

Now open Item Card → Inventory Planning → Calculation Log and read the entry. It shows the demand statistics, the lead time and its source, the Z-score, and the previous value. If the numbers look wrong, this is where you find out why — usually the history window or the demand definition, not the arithmetic.

5. Roll out to a range

Do not start with a bulk apply. Use the Planning Worksheet:

  1. Item List → Inventory Planning → Planning Worksheet
  2. Load Items, filtered to one item category or one vendor
  3. Read the variance message — it tells you how many lines move the reorder point by more than 25%. Check those first.
  4. Tick the lines you accept, then Apply Selected

6. Schedule it

Inventory Planning Setup → Create Job Queue Entry creates a daily 03:00 recurring entry, on hold so you can review it. Set it to Ready when you are satisfied.

See Running the calculators for the parameter values that control what each scheduled run does.

7. Set a log retention policy

The log grows by one row per item per calculator per run. Search for Retention Policies, add one for the GSO Calculation Log table, and set a period — 90 days is a sensible start. Without a policy, nothing is ever deleted.
